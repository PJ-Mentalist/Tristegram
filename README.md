# Tristegram

Клиент Telegram для ПК с красивым iOS-стилем: стекло, размытие, плавные анимации, оранжевый логотип с настраиваемым цветом.

## Что внутри

| Папка | Что это |
|---|---|
| `prototype/` | Интерактивный прототип интерфейса (`index.html`, открывается в браузере). Здесь проверяем дизайн и функции до сборки клиента. |
| `web-plugin/` | Первая версия стиля в виде JS-плагина для веб-интерфейсов. |
| `docs/` | Скриншоты. |

## Прототип умеет

- Шапка: аккаунты с быстрым переключением (Ctrl+1…3), надпись Tristegram с меню, часы и пинг, панель приложений.
- Меню сообщения как в Telegram: реакции, ответ, пересылка, изменение, закреп, выбор, «Подробности» (ID и дата с миллисекундами).
- Боковое меню, режим стримера, ночной режим.
- Настройки: темы, градиенты, фон чата (узор, цвет, градиент, фото/GIF/видео), анимации, форма и рамка аватарок, формат времени, приватность, активность как в Discord, приложения (Spotify, SoundCloud, ИИ, Google, мини-игра), режим экономии.

Данные в прототипе — примеры. Музыка, ИИ и подключение сервисов имитируются.

## План

1. Довести дизайн в прототипе.
2. Перенести его в форк [exDesktop](https://github.com/metawka/exDesktop) (GPL-3.0) и собирать `.exe` через GitHub Actions.
